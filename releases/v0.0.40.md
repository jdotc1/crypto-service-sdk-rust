# crypto-service-sdk-rust 0.0.40

## Highlights

- A typed async client for all 59 v2 operations of crypto-server, with a
  blocking client behind the `blocking` feature.
- Keys, passwords and plaintexts in zeroising, `Debug`-redacted types;
  errors that never carry a secret.
- The Crypto Service conformance kit (119 vectors) passes against a live
  server in CI, through the typed methods.
